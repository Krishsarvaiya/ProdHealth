# ProdHealth – The Packet Food Analyzer

## 📌 Overview

**ProdHealth** is a Packet Food Analyzer that helps users understand packaged food products by analyzing their nutritional information and ingredients. The goal is to make food labels easier to read and support healthier, informed choices.

The project focuses on:

* Interpreting packet food details
* Highlighting nutritional values
* Making food analysis simple and user-friendly

---

## 🚀 Features

* Analyze packaged food information
* Display nutrition-related insights
* Simple and beginner‑friendly project structure

## ⚙️ Installation & Setup

Follow these steps to run the project locally:

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Krishsarvaiya/ProdHealth.git
cd ProdHealth
```

### 2️⃣ Create a Virtual Environment (Optional but Recommended)

```bash
python -m venv venv
```

Activate it:

* **Windows**

```bash
venv\Scripts\activate
```

* **Mac/Linux**

```bash
source venv/bin/activate
```

### 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 4️⃣ Run the Project

```bash
python app.py
```
